##  Project Objective
FacePay is a smart payment system that uses face recognition to make digital payments easier, 
faster, and more secure. Instead of using passwords, PINs, or OTPs, it verifies users by 
scanning their faces. This makes the process more convenient and helps stop problems like 
OTP fraud, phishing, or someone else using your account. FacePay works for both wallet 
transfers and bank payments, and it connects easily with current payment systems to complete 
transactions quickly.
